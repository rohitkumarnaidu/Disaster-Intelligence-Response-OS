# Deterministic 5-Factor Priority Scoring Engine

<span className="badge-implemented">Implemented</span>

DRAXELYRA rejects opaque black-box prioritization. The Priority Engine computes a fully deterministic, explainable score between $0$ and $100$ using a transparent mathematical formulation implemented in `artifacts/api-server/src/lib/priority.ts`.

---

## The Mathematical Formula

$$	ext{Priority Score } (P) = 	ext{round}Big(0.30 cdot S + 0.25 cdot C + 0.20 cdot E + 0.15 cdot U + 0.10 cdot (K 	imes 100)Big)$$

Where:
- **$S$ = Structural Damage Severity Score** ($0	ext{--}100$)
- **$C$ = Critical Infrastructure Score** ($0	ext{--}100$)
- **$E$ = Exposed Population / Density Score** ($0	ext{--}100$)
- **$U$ = Urgency & Access Constraint Score** ($0	ext{--}100$)
- **$K$ = AI Model Confidence Metric** ($0.00	ext{--}1.00$)

---

## Exact Factor Weight Matrices

### 1. Severity Weight ($S$) — $30%$ Weight
Derived from optical spectral classification or SAR backscatter loss:
- `DESTROYED` $	o 100$
- `SEVERE` $	o 75$
- `MODERATE` $	o 45$
- `UNCERTAIN` $	o 35$
- `MINOR` $	o 20$
- `NO_DAMAGE` $	o 0$

### 2. Criticality Weight ($C$) — $25%$ Weight
Derived from impacted OpenStreetMap infrastructure:
- `HOSPITAL`, `EMERGENCY_SERVICES`, `TRAUMA_CENTER` $	o 100$
- `BRIDGE`, `EVACUATION_ROUTE`, `AIRPORT` $	o 85$
- `POWER_SUBSTATION`, `WATER_TREATMENT`, `CELL_TOWER` $	o 75$
- `SCHOOL`, `COMMUNITY_SHELTER` $	o 70$
- `RESIDENTIAL_HIGH_DENSITY` $	o 40$
- `COMMERCIAL_INDUSTRIAL` $	o 30$
- `DEFAULT_UNCLASSIFIED` $	o 15$

### 3. Exposure Weight ($E$) — $20%$ Weight
Derived from LandScan / WorldPop gridded population density within the 500m hazard buffer:
- `HIGH` ($> 500 	ext{ persons/hectare}$) $	o 90$
- `MEDIUM` ($100	ext{--}500 	ext{ persons/hectare}$) $	o 55$
- `LOW` ($< 100 	ext{ persons/hectare}$) $	o 20$

### 4. Urgency Weight ($U$) — $15%$ Weight
Implements a 72-hour exponential decay curve with access constraint penalties:
$$U = minleft(100, maxleft(0, 100 - rac{	ext{hoursElapsed}}{72} 	imes 100ight) + (	ext{accessConstrained}  ?  20 : 0)ight)$$

### 5. Statistical Confidence ($K$) — $10%$ Weight
The direct confidence probability ($0.0	ext{--}1.0$) generated by the multimodal AI model multiplied by 100.
